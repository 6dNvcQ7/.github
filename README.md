# .github

6dNvcQ7 所有 repo 共用的預設範本。repo 自己沒有範本時，GitHub 會自動套用這裡的版本；repo 有自己的範本時，這裡的同類範本整份不會套用。

- `.github/pull_request_template.md`：PR 範本 (需要你、變更、驗證、合併風險、合併前確認)
- `.github/ISSUE_TEMPLATE/task.md`：Issue 範本「一般任務」(目標、驗收條件、範圍外、相依)

填寫規則在 6dNvcQ7/agent-skills 的 `repo-conventions`、`pr`、`issue` 技能；各 repo 的專屬規則寫在該 repo 的 AGENTS.md。

本 repo 必須保持公開，預設範本才會生效。不要放入任何私人資料。
